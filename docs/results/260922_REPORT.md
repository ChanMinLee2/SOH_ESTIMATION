
## 안건 2 — 오류 수정 후 시나리오 유무 성능 비교 재검증

### 2-1) v4 버전 noscen vs scen 비교

| 조건 | test R²(oracle) | test R²(hard) | run |
|---|---|---|---|
| noscen | **0.9504** | 0.9504 | `0918_1800_..._noscen_lag1full_seed42` |
| scen | 0.9437 | 0.9080 | `0918_2250_..._scen_lag1zone_seed42` |

noscen이 scen의 oracle보다도 높고, scen의 hard와는 더 크게 벌어진다 — 안건 1 수정을 전부
반영한 뒤에도 **noscen > scen** 패턴 유지. scen의 hard 손실은 "파편화로 인한 학습 열화" +
"배포 시 라우팅 오류"가 겹친 결과로 해석.

### 2-2) 멀티시드 검증 (seed 0/42/123, split-seed=seed)

| 조건 | test R²(oracle) 평균±표준편차 | test R²(hard) 평균±표준편차 |
|---|---|---|
| noscen | 0.9478±0.0043 | 0.9478±0.0043 |
| scen | 0.9389±0.0070 | 0.8908±0.0180 |

noscen 평균이 scen보다 항상 높고 표준편차도 더 작음 — 2-1과 일관.

**HI 선택 안정성 — 파편화 가설의 4·5번째 독립 증거**(`docs/260917_REPORT.md`의 3가지
독립 증거에 추가):

| 비교 축 | noscen | scen (6시나리오 평균) |
|---|---|---|
| 시드 간 유사도(같은 시나리오, 다른 seed) — Jaccard / Kendall τ | 0.861 / 0.852 | 0.53~0.68 / 0.59~0.67 |
| 시나리오 간 유사도(같은 seed, 다른 시나리오) — Jaccard / Kendall τ | **1.000** / **1.000** | **0.780** / **0.741** |

**핵심 발견**: scen에서 "시나리오 간" 유사도가 "시드 간" 유사도보다 항상 더 높다 — 정상적인
시나리오 조건화라면 반대여야 한다(시나리오마다 다른 HI가 필요하다면 시나리오 간 차이가
시드 노이즈보다 커야 함). 즉 `scen_gates`는 시나리오별로 특화된 피처를 고르는 게 아니라,
**noscen과 거의 같은 하나의 HI 세트를 시나리오 수만큼 쪼개진 적은 샘플로 각자 더
불안정하게 재발견**하고 있다 — 지금까지 중 가장 직접적인 파편화 증거.

### 2-3) HI 그룹별 비교 (63 / 64 / 66)

`diff_dqdv_area`도 `stat_q_abs`/`stat_energy_seg`와 같은 leakage 계열로 보고 제외를
권했던 지난 판단을 실측으로 검증 — scen 축에서 HI63(q_abs/energy/dqdv_area 전부 제외),
HI64(기본, q_abs/energy만 제외), HI66(전부 포함) 비교(seed=42):

| 조건 | N_HI | test R²(oracle) | test R²(hard) |
|---|---|---|---|
| HI63 | 63 | 0.9208 | 0.8287 |
| HI64(기본) | 64 | 0.9437 | 0.9080 |
| HI66 | 66 | **0.9511** | 0.9034 |

- **oracle은 HI가 많을수록 단조롭게 좋아진다**(0.9208 < 0.9437 < 0.9511) — leakage 계열로
  보고 제외를 권했던 지난 판단과 **정반대**. 상관이 높다고 순수 대리 변수는 아니었고,
  다른 HI로 대체되지 않는 고유 신호를 갖고 있었던 것으로 해석.
- **단, hard는 HI64가 근소하게 1위**(0.9080 > 0.9034 > 0.8287) — HI가 늘수록 라우팅이
  더 어려워졌을 가능성(격차 작아 seed 하나로는 단정 이름).
- **다음 액션**: (1) "q_abs/energy 유지, dqdv_area만 제외"하는 HI65로 기여 분리, (2) HI64
  vs HI66 hard 역전 멀티시드 재현 확인, (3) `diff_dqdv_area` 기본 포함으로 되돌리는 것 검토.
