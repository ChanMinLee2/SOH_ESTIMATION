## 충전 프로토콜

### 기본 구조

전 배치(1~10) 동일한 **단일 CC-CV** 프로토콜.

| 단계 | 내용 |
|------|------|
| Step 1 | **5.5A (≈4.5C) CC** → 컨트롤러 SOC 타겟(≈72~73% SOC) 도달까지 |
| Step 2 | **1.1A (≈1C) CC-CV** → 3.6V 도달 후 CV, 전류 컷오프까지 |
| 방전 | 1C CC, 2.75V 컷오프 (추정) |

모든 배치에서 `I_max = 5.50A`, `1C = 1.10A` 완전 균일.

**SOC 타겟**: 5.5A CC → 1C 전환점이 q_frac ≈ **0.70~0.73** (초기 사이클 실측).  
공칭 용량(≈1.2Ah) 기준 약 70~73% SOC에 해당.  
(MIT의 80% SOC 타겟과 달리 HUST는 더 낮은 SOC에서 1C로 전환)

### 충전 중 두 개의 전환점

```
전환 1: 5.5C CC  →  1C CC   (컨트롤러 타겟: q_frac ≈ 0.72, 약 72% SOC)
전환 2: 1C CC   →  3.6V CV  (전압 도달 시점: 열화에 따라 크게 변동)
```

| 전환 | 기준 | 비고 |
|------|------|------|
| 5.5C CC → 1C CC | q_frac ≈ 0.72 고정 | 컨트롤러 SOC 타겟 |
| 1C CC → 3.6V CV | q_frac 0.70~0.97 | R↑에 따라 사이클마다 변동 |

### 열화 단계별 충전 동작

HUST 셀은 MIT와 달리 CV 침범이 **chg_mid까지 진행되는 경우가 드물다** (77셀 중 5셀, 6.5%).  
대부분의 셀은 EOL까지 CV 시작점이 **chg_hi 내에서** 이동한다.

#### 단계별 동작 설명

**초기 (~용량 보존 구간, cv_qfrac ≈ 0.96)**
```
5.5C CC → [q_frac≈0.72, ~72% SOC] → 1C CC → [q_frac≈0.96, 3.6V 도달] → CV
                                       ←── ~0.24×Qt 추가 충전 ──→
```
- 1C CC 구간에서 총 용량의 ~24%를 추가 충전한 뒤 3.6V에 도달
- CV 시작점이 chg_hi 후반부(q_frac ≈ 0.97)에 위치

**중기 (저항 급증 이후, cv_qfrac ≈ 0.72~0.83)**
```
5.5C CC → [q_frac≈0.72] → 1C CC → [빠른 3.6V 도달] → CV
```
- R↑ → 1C CC 시작 직후 3.6V cutoff 도달 (1C CC 유효 구간 축소)
- cv_qfrac이 0.96에서 ~0.76으로 **급격히 하락** (사이클 수십~수백 내 전환)
- CV 시작점이 chg_hi 내에서 경계(q_frac=0.70) 방향으로 이동

**말기 (일부 셀, cv_qfrac < 0.70)**
```
5.5C CC → [q_frac<0.72에서 3.6V cutoff — SOC 타겟 미달] → CV
```
- 5.5C CC 자체가 3.6V에 먼저 걸림 (MIT b3c44 말기와 동일 메커니즘)
- CV 시작점이 **chg_mid**(q_frac < 0.70)로 진입
- 전체 77셀 중 5셀(6.5%)에서만 발생

### MIT vs HUST 프로토콜 비교

| 항목 | MIT | HUST |
|------|-----|------|
| fast CC C-rate | 3.3~5.5C (셀마다 다름) | **5.5C 전 셀 균일** |
| fast→1C 전환 SOC 타겟 | **~80% SOC** (≈0.80Ah) | **~72% SOC** (q_frac≈0.72) |
| 초기 CV 시작 q_frac | 0.97 (대부분) | **0.97 (전 셀 균일)** |
| 말기 CV 시작 q_frac | 0.51~0.97 (셀 차이 큼) | 0.68~0.87 (범위 좁음) |
| chg_mid CV 침범 비율 | 높음 (열화 빠른 셀) | **낮음 (5/77 = 6.5%)** |
| 급격한 cv_qfrac 하락 | 사이클별 점진적 | **특정 구간에서 급격한 하락** |

> HUST는 용량이 초기값의 약 93~95% 수준으로 떨어지는 시점에서 1C CC의 3.6V 도달이  
> 급격히 빨라지는 전환이 관찰된다. 이 시점이 cv_qfrac 0.96 → 0.77 급락 구간과 일치.
