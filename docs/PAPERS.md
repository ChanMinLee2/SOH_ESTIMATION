## 1. iMOE — prediction of second-life battery degradation trajectory using interpretable mixture of experts

**서지정보**: Huang, Tao et al., *Nature Communications* 17:2549 (2026). DOI: 10.1038/s41467-026-69369-1.
파일: `docs/iMOE prediction of second-life battery degradation trajectory using interpretable mixture of experts.pdf`

### 1.1 데이터셋

3개 독립 데이터셋, 총 295배터리 / 93사용조건 / 84,213사이클(게재판 최종 수치 — arXiv
프리프린트 단계 수치는 207배터리/77조건/67,902사이클로 달랐음, 최종판 기준으로 통일).

| 데이터셋 | 검증 목적(시나리오) | 구성 |
|---|---|---|
| **UL**(Uniform-Life) | 과거·미래 조건은 같지만 과거 이력 데이터가 없는 경우 | 18650 상용셀 130개, 3배치(NCA 3500mAh / NCM 3500mAh / NCM+NCA블렌드 2500mAh), 25/35/45°C × 0.25C~4C충전 × 고정1C방전, EOL까지 전 생애 동일 프로토콜 |
| **LSD**(Late-Stage Degradation) | 과거 이력 불명 + 이미 깊게 열화된 경우 | NCM/흑연 2.4Ah 86셀. Phase1: 16가지 프로토콜로 SOH 100%→80% 유도(이력 다양화) → Phase2: 전 셀 공통 저율(0.5C충/0.2C방)으로 80%→50% 재사이클(예측 대상) |
| **TPSL**(Two-Phase Second-Life) | 2차 사용조건이 1차와 크게 다른 경우 | 18650 LCO/NCM 2.4Ah 77셀. Phase1: 0.5C CCCV충/2C방 20사이클 → Phase2: **Random**(55셀, 1C/2C/3C 충전을 5사이클마다 랜덤 변경+고정3C방전) / **Fixed**(22셀, 사전 정해진 충방전 조합) |

### 1.2 세그먼트(부분 사이클) 분할·정의 방식

**전압 기준**(용량 비율 기준 아님). 한 사이클에서 두 신호만 사용:

- **부분 충전 곡선**: 전압구간 `[V_min, V_end]`을 50등분(M=50)해서 각 지점까지 누적
  전하량 `q_i(V)=∫I(t)dt`를 추출. **`V_min`은 사이클마다 랜덤**(현장에서 셀을 수거했을 때
  초기 SOC가 무작위인 상황을 시뮬레이션), **`V_end`는 고정 컷오프 전압**(프로토콜 상수).
- **완화전압(relaxation voltage) 곡선**: 충전 종료 직후 30분간 개회로전압을 51개 지점(M+1)으로 기록.

경계 중 하나(`V_end`)는 완전 고정, 다른 하나(`V_min`)는 랜덤이지만 **SOH·용량과 무관한
전압값**이라 라벨 얽힘이 없음 — SCR의 `vqslope`(라벨-독립 경계) 원칙과 같은 계열.
`q_frac_wide`처럼 그 사이클 실측 총 용량 대비 비율은 전혀 쓰지 않는다.

### 1.3 전처리 / 피처 엔지니어링

- 두 곡선에서 **12개 물리 기반(physics-informed) 피처** 추출(분극 과전압, 완화 기울기,
  전압 플래토 전환 등) → `[0,1]` 정규화.
- 모델 최종 입력 = **부분 충전 곡선 원본 `q∈R^50`** + **12차원 피처 `F_i`** — 서로 다른
  용도(아래 1.4)로 쓰임.

### 1.4 모델 입력 → 내부 구조

**AMDP(Adaptive Multi-degradation Prediction)** — 게이팅+전문가 회귀:
- 라우터: `g(F_i)=Softmax(TopK(Softmax(F_i·W_g+ψ·Softplus(F_i·W_noise)), k))` — Shazeer 2017
  (Sparsely-Gated MoE)과 동일한 noisy top-k 게이팅. **12차원 피처 `F_i`만** 라우터 입력.
- 각 `Expert_j`는 **원본 충전곡선 `q_i`**(피처 아님)를 받아 잠재 열화모드 기저함수들의
  가중합으로 단기 추세를 출력: `Expert_j(q_i)=Σ_θ w_j(θ)·φ(q_i;θ)`.
- `Trend_i = Σ_j g_j(F_i)·Expert_j(q_i)` — 출력 자체가 `L`(예측 지평 길이)차원 시퀀스.

**FORNN(Future-Operation RNN)**:
- 미래 부하 조건 `C_i=[(I_chg,I_dis,T)^(1),...,^(L)]`(가정된 미래 충방전전류·온도)를
  `Trend_i`와 concat → LSTM에 순차 입력 → `Ŝ_i`(향후 L사이클 용량 궤적) 출력.

### 1.5 제안 알고리즘(학습)

- Loss = `α·L_traj + β·L_router` (α=0.75, β=0.25)
  - `L_traj`: 궤적 MSE.
  - `L_router`: 전문가 사용 빈도의 변동계수(분산/평균²) 벌점 — "expert collapse" 방지용
    로드밸런싱 항(Switch Transformer류 표준 MoE 보조손실과 동일 발상).
- 최종 하이퍼파라미터: **전문가 5개, TopK=2**(전문가 수엔 비교적 둔감, 성능·배포 균형 후 채택).

### 1.6 성능 결과

- **전체**: 평균 MAPE **0.95%**, 추론 **0.43ms**/배터리.
- **SOTA 대비**(PatchTST/Informer): MAPE 77%↓, 추론시간 50%↓. (iMOE 0.95%·0.43ms vs
  PatchTST 4.15%·0.58ms vs Informer 4.74%·0.87ms)
- **데이터셋별 평균 MAPE±std**: UL 0.52%±0.28%, LSD 1.81%±0.13%, TPSL-Fixed 2.96%±0.44%,
  TPSL-Random 2.81%±0.15%.
- **150사이클 장기 예측**: 평균 1.50%, 최대 6.26%.
- **초기 SOC 강건성**: 5개 랜덤 초기 SOC 구간 검증. 초기 SOC 50%가 최악(고SOC 구간엔
  OCV 정보가 적음), 20%로 낮추면 평균 최대 63.8% 개선.
- **데이터 축소 내성**: 학습데이터 20%(~32셀, 5MB)까지 줄여도 UL은 MAPE 1.07% 유지
  (TPSL은 5.30%로 더 민감).
- **Ablation**: AMDP→단순 FC 교체 시 MAPE 0.95%→1.19%(게이팅 구조 기여 확인).
  FORNN→일반 RNN 교체 시 TPSL에서 급락(미래 부하 조건 반영 필요성 확인).
- **참고**: 과거 이력 데이터가 있다는(iMOE 전제와 다른) 조건에서는 단순 다항식 피팅(0.79%)·
  1층 MLP(0.93%)가 iMOE의 history-free 0.95%와 비슷하거나 더 낮음 — iMOE의 가치는
  "더 정확해서"가 아니라 "이력 데이터 없이도 그 수준이 나온다"는 데 있음.
- **해석가능성**: 라우터 가중치가 초기/중기/말기 열화 샘플마다 다른 전문가에 주로
  라우팅됨을 확인(SEI형성→SEI두꺼워짐→리튬도금 단계와 대응), 전문가 가중치만으로
  은퇴 SOH 역추정 가능(95%SOH→"우수" 신뢰도 91.5%).

## 2. A sparse SOH estimation framework based on clustered voltage segments and multi-head CNN

**서지정보**: Ke, Lin, Meng, Wu, Wang, Wang, *Energy* 344 (2026) 140057, Elsevier.
DOI: 10.1016/j.energy.2026.140057.
파일: `docs/A sparse SOH estimation framework based on clustered voltage segments.pdf`

### 2.1 데이터셋

| 데이터셋 | 사양 | 프로토콜 | 온도 |
|---|---|---|---|
| Dataset 1 (자체 실험) | 18650 NMC, 1.5Ah, 3.6V, 2.5–4.2V | 0.67C/1.33C CC-CV충전 + 5C/10C방전(셀별 조합 다름), 4셀 약 1년 사이클링, 1Hz 샘플링 | 25°C |
| Dataset 2 (Oxford 공개셋, Artemis 도심주행 사이클 기반) | 18650 LC(층상산화물), 0.74Ah, 3.6V | 0.05C/1C CC-CV충전 + 1C방전, 1Hz 샘플링 | 30°C |
| Dataset 3 (MIT LFP, Severson 2019) | 18650 LFP, 124셀, 1.1Ah, 3.3V, 2–3.6V | 2단계 급속충전 I1(Q1)-I2 + 4C방전, 가변 샘플링 주파수 | 40°C |

### 2.2 세그먼트(부분 사이클) 분할·정의 방식

**전압 기준, 양쪽 경계 모두 고정**(iMOE와 차이점 — iMOE는 한쪽만 랜덤).

- "임의 충전(arbitrary charging)" = 시작·종료 SOC 무제약, **20–95% SOC 범위 내**에서
  가변 충전율 — 컷오프 근처 CV 테이퍼 구간(비정상성 심함)은 명시적으로 제외.
- `U_start`(=20%SOC 고정): 운전자가 range anxiety 때문에 보통 20% SOC를 남겨두고,
  그 근처에서 충전을 시작하는 게 수명에도 유리하다는 실사용 근거로 고정.
- `U_end`(=95%SOC 고정): CV 구간(전류가 단조 감소하며 불안정) 회피 목적으로 완충 컷오프
  살짝 아래로 고정.
- `[U_start, U_end]`를 `N=20`개 세그먼트로 균등 분할(폭 `ΔU=(U_end-U_start)/N`), 각
  세그먼트를 다시 `n=10`개 등간격 전압 지점으로 리샘플 — **원 샘플링 밀도와 무관하게
  항상 고정 길이(10포인트) 표현**이 되도록 설계.
- 실험적으로는 세그먼트 개수(1~20)와 전압 구간(폭·위치)을 각각 바꿔가며 성능을 스윕하고,
  **세그먼트 개수별 100회 랜덤 샘플링 실험**으로 강건성까지 검증(§2.6 참조) — 이 랜덤화가
  "임의 충전"을 시뮬레이션하는 실질적 장치.

### 2.3 전처리

- `Q(t)=∫I(t)dt`(쿨롱 카운팅) → 전압 트레이스와 정합해 `Q(V)` 구성 → **선형보간으로
  균일 전압격자 `V_k`(간격 `h`)에 리샘플** → 구간 기반 유한차분으로 IC 계산:
  `IC ≈ [Q(V_k+h)-Q(V_k)]/h`.
- 이 "구간 기반"(포인트 대 포인트가 아닌) 미분 방식을 **의도적으로 채택한 이유**: mV급
  측정 잡음/비균일 샘플링에서 발생하는 인접 포인트 간 급격한 미분값 튐을 완화하면서도
  IC 피크 위치·폭은 안정적으로 보존.
- 결과 `Δq`(IC) 시퀀스는 전기화학적 상전이에 대응하는 뚜렷한 피크·골을 보이며(NMC 기준
  ~3.75V/3.95V/4.10V), 열화에 따라 피크가 이동·감쇠 — 이게 핵심 열화 민감 피처.

### 2.4 모델 입력 → 내부 구조

**주의**: 이 논문엔 "head"가 두 가지 다른 의미로 쓰인다 — (a) K-means 클러스터당 1개씩
배정되는 **CNN 브랜치**(K=5개), (b) 융합 단계의 표준 **멀티헤드 어텐션**(H=4개, (a)와 무관).

- 입력: K개 클러스터별로 그 배치에 속한 세그먼트만 모아 `X_i∈R^(B×d)`(빈 클러스터는 스킵).
- **Multi-head CNN**: 클러스터(K=5)마다 독립 브랜치 — 각 브랜치는 1D-conv 3층
  (96→64→32채널, kernel=2, stride=1, ReLU) → 시간축 평균풀링 → FC 2층.
- **어텐션 융합**: 그 배치에서 실제로 데이터가 있는(non-empty) 브랜치 집합 `I`만 대상.
  브랜치별 표현을 공유 임베딩 공간으로 사상 → 평균해 쿼리 `Q` 생성, 브랜치별 `K_i,V_i`
  선형 사상 → scaled dot-product attention(**활성 브랜치에만** softmax) → 가중합 `z`.
- 최종: FC 3층(64→32→1, 앞 2층 dropout 0.5)으로 SOH 스칼라 출력.
- 규모: **137.9K 파라미터, 1.89 MFLOPs, 피크 메모리 8.6MB, 추론 0.9ms**(RTX4050 기준).

### 2.5 제안 알고리즘

1. (오프라인, 1회) 학습 데이터의 세그먼트별 `Δq` 특징벡터에 **K-means 클러스터링**
   (K는 Gap statistic + 1-SE 규칙으로 자동 선정, 후보 K=2~8 중 **K=5** 채택 — K=7이
   조금 더 높아도(51.67% vs 48.42%) 1-SE 이내라 더 작은 K 선택. GMM/Agglomerative
   대비 DBI·CH 내부타당도 지표로 K-means가 최선임을 확인).
2. 이 클러스터링이 만든 **(세그먼트 인덱스 → 클러스터 → CNN 브랜치) 매핑은 그 이후
   완전히 고정(frozen)** — 매 사이클/매 배치마다 재군집하지 않음. **SCR·iMOE와의 핵심
   차이점**: 이 논문의 라우팅은 학습되는(differentiable) 게이트가 아니라, 신경망 학습
   시작 전에 끝나는 **비모수적·정적 룩업**이다.
3. Multi-head CNN + Attention을 Adam(lr=0.001, batch=50, 500epoch, 조기종료·증강 없음)으로 학습.
4. Ablation 축: `CNN`(단일헤드, 클러스터링 없음) → `Multi-CNN`(다중헤드지만 클러스터링
   없이 위치 그대로) → `Cluster-Multi-CNN`(클러스터링 라우팅 추가) → `Cluster-Multi-CNN-ATTN`(어텐션 융합 추가, 최종 제안).

### 2.6 성능 결과

- 짧은 세그먼트(정보 적음)~긴 다중세그먼트(정보 많음)를 아우르는 **8개 케이스(a~h)**에서
  Cluster-Multi-CNN-ATTN이 일관되게 최상 — 예: Case(h) MAE 0.95%(Transformer 1.49%,
  CNN-LSTM 1.57%, Informer 1.60%보다 우수). Case(c) MAE 1.37%/RMSE 1.75%/R² 92.21%(8개
  비교모델 중 최고).
- **Ablation 정량화**: Case(d)에서 클러스터링 추가만으로(Multi-CNN→Cluster-Multi-CNN)
  RMSE 1.10%p 감소, R² 79.90%→92.48%.
- **세그먼트 개수 스윕**(3개 데이터셋 3D surface): 4~6개만으로도 전반적 열화 추세 포착,
  개수 늘수록 매끄러워짐 — 25°C/30°C/40°C, NMC/LC/LFP 전 조건에서 일관.
- **전압 구간(위치·폭) 스윕**: 위치가 성능을 크게 좌우 — 층상산화물의 변곡점(inflection
  point) 부근이나 올리빈(LFP)의 플래토 전이(transition) 부근을 포함하면 RMSE가 급감
  (예: NMC 좁은창 3~4% → 변곡점 포함 시 0.8~1.0%; LFP 플래토 내부만 4~6% → 전이구간
  포함 시 ~1%) — **정보가 많은 구간은 "형상이 급변하는 곳"이라는 점에서 SCR의 vqslope
  설계 근거(형상 랜드마크가 정보가 많다)와 같은 결론**.
- **100회 랜덤 샘플링 강건성**(세그먼트 개수 1~20 × 100trial): 1세그먼트 RMSE 3.5%↑
  (분산 큼) → 6세그먼트 중앙값 2%↓ → 10개 이상 대개 1.2%↓(분산도 줄어듦), 3개 데이터셋
  전부 동일 경향.
- **초경량 조건**: 전압창 0.11V로 좁혀도 RMSE ≈1.7%, 0.275V면 ≈0.8%.
- **실무 가이드(저자 명시)**: 부분충전 데이터가 **최소 1개의 완전한 로컬 전압창**을
  커버할 때만 SOH 추정을 권장 — 너무 일찍 중단된(예: 잠깐 꽂았다 뺀) 충전은 비권장.
- **한계(저자 인정)**: CV 구간 특징추출 미포함, 실제 EV 로그/팩 단위 검증 필요, 향후
  과제로 불확실성 정량화·전이학습/few-shot·적응형 세그먼트 분류(열화에 따른 피처 드리프트
  대응) 언급.

## 3. SCR 프레임워크와의 비교 요약

| 항목 | SCR(본 프로젝트) | iMOE(Nat Commun 2026) | Cluster-Multi-CNN-ATTN(Energy 2026) |
|---|---|---|---|
| 라우팅/게이팅 축 | **관측 구간**(어느 부분을 봤는지 — q_frac_wide/vqslope 등) | **열화 모드**(SEI형성/두꺼워짐/리튬도금 등 물리적 상태) | **전압 세그먼트 형태 유사도**(K-means 군집, 물리적 열화모드와 무관) |
| 라우팅 메커니즘 | 학습되는 Hard-Concrete/L0 게이트(연속 완화, 미분가능) | 학습되는 noisy top-k MoE 게이트(미분가능) | **오프라인 1회 K-means, 이후 고정 룩업**(비학습·비미분) |
| 부분 관측 경계 정의 | q_frac_wide: 그 사이클 실측 총량 대비 비율(라벨 얽힘 위험) / vqslope: 형상 랜드마크(라벨 독립) | 전압 기준, `V_min` 랜덤 + `V_end` 고정(라벨 독립) | 전압 기준, `U_start`·`U_end` **둘 다 고정**(20%~95%SOC, 라벨 독립) |
| 입력 피처 | 카테고리별(stat/diff/lfp/morph) HI, 시나리오별 L0로 서브셋 선택 | 12개 물리기반 피처(라우팅용) + 원본 곡선(전문가 입력용) 분리 | IC(`Δq`) 시퀀스 단일 계열, 특징선택 없이 원 세그먼트 그대로 CNN 입력 |
| 비용 인식 | HI 카테고리별 계산비용을 L0 페널티에 명시 반영(cost-aware) | 명시적 비용 항 없음(파라미터/추론시간은 결과로만 보고) | 명시적 비용 항 없음(경량 아키텍처 자체로 달성) |
| 크로스 도메인 전이 | Phase1 게이트 동결 + Phase2 헤드만 few-shot 적응(HUST 10-shot R²=0.813) | 조건 넘어 일반화(77~93개 조건을 한 모델로 흡수) — "미학습 도메인 전이"는 별도 검증 안 됨 | 3개 화학종(NMC/LC/LFP) 개별 데이터셋 내 검증, 데이터셋 간 전이 실험 없음 |
| 대표 성능 | (축·조건별로 다름, 진행 중) | MAPE 0.95%, 0.43ms, 137.9K~수준 파라미터(비공개) | RMSE ~1.7%(0.11V창)~0.8%(0.275V창), 137.9K 파라미터, 0.9ms |

**시사점**:
1. 두 논문 모두 "부분 관측 + 조건별 라우팅 + 경량 모델"이라는 SCR과 같은 큰 틀에 이미
   도달해 있어, SCR이 이 틀 자체를 기여로 내세우기는 어렵다.
2. SCR이 차별화할 수 있는 지점은 좁게 셋으로 압축된다 — ① 라우팅 축이 "열화 모드"나
   "형상 유사도"가 아니라 **명시적으로 라벨-독립적인 관측 조건**이라는 프레이밍(단,
   q_frac_wide는 이 원칙을 어기므로 vqslope 중심으로 서술해야 함), ② HI **카테고리별
   비용을 정규화항에 직접 넣는** cost-aware 설계(두 비교논문 모두 이런 명시적 비용 항이
   없음 — 다만 우리도 아직 Pareto 곡선을 실측하지 않은 상태), ③ **미학습 새 데이터셋에
   대한 few-shot 전이**라는, 두 비교논문이 검증하지 않은 문제 설정.
3. Cluster-Multi-CNN-ATTN의 "정적 K-means 라우팅"은 SCR/iMOE의 "학습되는 게이트"보다
   단순하지만, 그 대신 해석 가능성·안정성 면에서 오히려 강점으로 제시된다는 점도 참고할
   만하다 — 우리 L0 게이트가 학습 시드에 따라 불안정하다는 기존 관찰(Hard Concrete의
   seed 민감도, `MODEL_DIRECTION.md` 실험 E)과 대조하면, "왜 학습되는 게이트가 정적
   클러스터링보다 나은가"도 논문에서 방어해야 할 지점이다.
