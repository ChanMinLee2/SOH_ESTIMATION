# HI 클러스터링 분석 — 시나리오 분류에 필요한 HI 수(m) 선정

## 1. 분석 목적

SOH 추정 파이프라인의 Stage A(시나리오 분류기)는 HI를 m개 입력받아 **Lo / Mid / Hi 3개 레벨**로 분류한다.
이 분석은 다음 두 질문에 답한다.

> Q1. HI 공간에서 3개 레벨이 얼마나 자연스럽게 분리되는가? (비지도 군집 구조 확인)  
> Q2. 몇 개의 HI를 사용해야 레벨 분류 성능이 포화되는가? (m 선정 근거)

충전/방전 여부는 입력 단계에서 이미 알고 있으므로 분류 대상이 아니다.
따라서 분석 단위는 **충전 그룹 / 방전 그룹** 2개이며, 각 그룹 내에서 Lo/Mid/Hi 3레벨 분류를 분석한다.

## 3. 분석 파이프라인

### 3-1. 전체 흐름

```
[1] 전체 데이터 로드
    _4_data_hi/seg/{MIT,HUST}/*.pkl → concat → 1,464,258행 × 71컬럼
    META_COLS(6개) + _dataset 제외 → 65개 HI 사용
    로드 시 _dataset 컬럼 추가 ("MIT" / "HUST") → 플롯 분리 표현 목적

[2] 그룹 분리
    scen ∈ {+1,+2,+3} → charging  (732,129행)
    scen ∈ {−1,−2,−3} → discharging (732,129행)
    y_lvl = |scen| − 1  (0=Lo, 1=Mid, 2=Hi)

[3] 표준화
    StandardScaler: 각 HI를 (x − μ) / σ 로 정규화
    → 단위/스케일 차이 제거, K-Means 유클리드 거리 안정화

[4] K-Means 클러스터링 (65차원 원공간)
    MiniBatchKMeans(k=2..9, batch_size=10,000, n_init=5)
    지표: Silhouette Score, ARI, NMI, KNN Purity
    ※ PCA는 시각화 전용. 클러스터링은 65D 그대로 수행.

[5] mRMR HI 랭킹
    65개 전체 HI를 후보로 두고, max_m=20개를 greedy 선택
    (상세 설명 → 3-2절)

[6] HI 수(m)별 성능 곡선
    mRMR top-m HI (m=1..20)로 다음 두 가지 측정:
      (a) sil_by_m  : K-Means k=3 Silhouette (비지도)
      (b) acc_by_m  : LogisticRegression 5-fold CV Accuracy (지도)

[7] 출력
    docs/clustering_plots/{charging,discharging}.png  — 3×3 패널 그림
    docs/_clustering_results.json                     — 수치 결과 전체
```

### 3-2. mRMR (Minimum Redundancy Maximum Relevance)

단순 MI 랭킹의 문제: 상관도가 높은 HI를 중복 선택해 실제로는 1개 HI의 정보만 담을 수 있다.

mRMR은 선택 단계마다 다음 점수로 후보를 평가한다:

```
Score(HI_i) = Relevance(HI_i) − Redundancy(HI_i)

Relevance(HI_i)   = MI(HI_i ; y_level)                  정규화 [0,1]
Redundancy(HI_i)  = mean |corr(HI_i, HI_already_selected)|
```

- **Relevance**: 전체 65개 HI에 대해 `mutual_info_classif`로 MI 계산 (50k 서브샘플)
- **Redundancy**: 이미 선택된 HI들과의 Pearson 상관계수 절댓값 평균
- **Greedy 선택**: 매 step에서 Score 최대 HI를 추가, 최대 20개 선택

결과로 얻는 것: 서로 중복되지 않으면서 레벨 분류에 유효한 HI 우선순위 목록

### 3-3. 분류 정확도 (acc_by_m)

mRMR top-m HI로 `LogisticRegression`을 학습해 5-fold CV accuracy를 측정한다.

```
학습기: LogisticRegression(C=1.0, max_iter=1000)
검증:   5-fold cross_val_score (stratified)
서브샘플: 50,000개 (전체 732k 대상 CV 속도 확보)
```

### 3-4. plateau_m 결정

sil_by_m 곡선에서 증분이 처음 0.005 미만이 되는 m:

```python
plateau_m = first m where sil_by_m[m] - sil_by_m[m-1] < 0.005
```

이 m 이후로 HI를 추가해도 군집 분리도가 실질적으로 개선되지 않는다. **m의 최소 권장값**이며 최적값이 아닐 수 있다.

## 4. 주요 지표 정의

| 지표 | 범위 | 의미 | 계산 방식 |
|------|------|------|-----------|
| **Silhouette Score** | −1 ~ 1 | 전역 군집 분리도. 0.5+ 이면 뚜렷한 구조 | 10k 서브샘플 |
| **KNN Purity** | 0 ~ 1 | 지역 군집 응집도. k개 이웃 중 동일 군집 비율 | 10k 서브샘플 |
| **ARI** | 0 ~ 1 | 예측 군집 vs 실제 레벨 일치도 (우연 보정) | 전체 |
| **NMI** | 0 ~ 1 | 예측 군집 vs 실제 레벨 정보량 겹침 | 전체 |
| **sil_by_m** | −1 ~ 1 | top-m HI로 k=3 Silhouette | 10k 서브샘플 |
| **acc_by_m** | 0 ~ 1 | top-m HI로 LogReg 5-fold 정확도 | 50k 서브샘플 |
| **plateau_m** | 정수 | sil_by_m 증분 < 0.005 첫 m | — |

### Silhouette vs KNN Purity

```
Silhouette (전역):
  s(i) = (b − a) / max(a, b)
  a = 자기 군집 내 평균 거리
  b = 가장 가까운 타 군집까지의 평균 거리
  → 군집 간 분리가 전체적으로 얼마나 명확한가

KNN Purity (지역):
  각 샘플의 k개 최근접 이웃 중 같은 군집 비율
  → 경계 부근에서 군집이 얼마나 섞이는가
  주의: knn=10 처럼 작은 값은 732k÷3=244k 클러스터 대비 너무 작아 purity ≈ 1.0 만 나옴
        의미 있는 측정을 위해 --knn 500 이상 권장
```

| Silhouette | KNN Purity | 해석 |
|:----------:|:----------:|------|
| ↑ | ↑ | 전역/지역 모두 뚜렷한 군집 |
| ↑ | ↓ | 전체 분리는 있으나 경계 흐릿 |
| ↓ | ↑ | 군집 모양 불규칙, 지역은 응집 |
| ↓ | ↓ | 군집 구조 없음 |

## 7. 결과 해석

### 7-1. 방전 그룹: k=3 ARI=0.999의 의미

방전 데이터에서 **K-Means k=3이 실제 레벨 레이블과 거의 완벽하게 일치**한다(ARI=0.999, NMI=0.998).
이는 65D HI 공간에서 Lo/Mid/Hi 세 레벨이 자연스러운 3개 구형 군집을 이루고 있음을 의미한다.

단 **Silhouette은 0.293으로 낮다**. 모순처럼 보이지만 다음을 의미한다:
- 3개 그룹은 실제로 존재하고 레이블과 정확히 대응됨
- 하지만 각 그룹의 형태가 구형이 아니거나 군집 간 거리가 좁음
- K-Means가 k=8로 더 쪼개면 더 컴팩트한 군집이 만들어져 Silhouette은 올라가지만, 그 8개 군집은 레벨과 무관해짐(ARI가 k=8에서 0.502로 감소)

결론: **방전 HI 공간은 레벨을 완벽히 인코딩**하나, 군집 경계가 선명하지 않은 형태.

### 7-2. 충전 그룹: best_k=5, ARI@k=3=0.500

충전 데이터는 방전과 다르게 k=3에서 ARI=0.500에 불과하다. 이는 K-Means k=3 군집이 레벨과 절반 정도만 일치함을 의미한다. 대신 k=4에서 ARI=0.814로 급등한다.

가능한 해석: 충전 데이터에서 Lo 레벨 내부에 두 개의 서브그룹(예: 초기 사이클 vs 후기 사이클)이 존재해 자연적으로 4개 군집이 형성될 수 있다. 반면 방전은 레벨이 더 명확히 구분된다.

### 7-3. acc_by_m의 실용적 해석

| 그룹 | m=1 acc | m=2 acc | 포화 acc | 해석 |
|------|:-------:|:-------:|:--------:|------|
| charging | 82.7% | **93.5%** | 94.0% | m=2에서 대부분 포화. m=1은 불충분 |
| discharging | **99.2%** | 99.2% | 100.0% | m=1만으로도 거의 완벽 분류 |

방전은 `stat_v_range` 하나만으로 99.2%의 레벨 분류 정확도를 달성한다. 이는 방전 구간에서의 전압 범위(= 충전 가능 용량의 프록시)가 SOH 레벨을 직접적으로 반영하기 때문이다.

### 7-4. Silhouette vs Accuracy 불일치

| 패턴 | 발생 그룹 | 의미 |
|------|----------|------|
| Sil ↑ + Acc ↑ | charging (m=1,2) | HI 공간의 군집이 레벨과 정렬. 이상적. |
| Sil ↓ + Acc ↑ | discharging 전반 | 레벨은 명확히 구분되나 군집 모양 불규칙 |
| Sil ↑ + Acc ↓ | 해당 없음 | — |

방전 그룹에서 sil_by_m은 m=1 이후 계속 떨어지지만 acc는 m=3부터 1.000이다. HI를 늘릴수록 분류 경계는 더 명확해지지만(acc ↑) K-Means 구형 군집과는 맞지 않게 됨(sil ↓).

## 10. 자주 묻는 질문 (Q&A)

### Q1. 산점도에서 k=3만 보여주는 이유는?

충전/방전 각 모드 내에서 분류해야 하는 레벨이 **Lo / Mid / Hi 3개**이기 때문이다.
`best_k` scatter는 "데이터가 자연스럽게 몇 개 그룹인가"를 보여주고, `k=3` scatter는 "모델이 실제로 사용해야 하는 k로 나눴을 때 어떻게 보이는가"를 확인한다. 두 패널을 함께 보면 자연 군집 수(best_k)와 목표 군집 수(k=3) 간의 차이를 직관적으로 파악할 수 있다.

### Q2. plateau_m의 의미는?

`sil_by_m` 곡선에서 **HI를 1개 추가할 때 실루엣 개선이 0.005 미만**이 되는 첫 번째 m이다.

```
예) m=1: sil=0.768
    m=2: sil=0.776  (+0.008 → 추가 효과 있음)
    m=3: sil=0.699  (−0.077 < 0.005 → plateau_m = 2)
```

"여기서부터 HI를 더 넣어도 클러스터 분리도 개선이 미미하다"는 의미로, **m의 최소 권장값**이다. acc_by_m이 같은 지점에서 포화된다면 두 지표가 동시에 수렴하는 최적 m으로 볼 수 있다.

### Q3. acc (LogReg 5-CV)의 의미는?

mRMR top-m HI만 입력으로 `LogisticRegression`을 학습해 **5-fold 교차검증 정확도**를 측정한다.

```
훈련/검증: 50,000개 서브샘플
5-fold: 각 fold마다 train 40k / val 10k
출력: 5개 fold 정확도의 평균
```

sil_by_m(비지도)과의 차이:

| | sil_by_m | acc_by_m |
|--|--|--|
| 방식 | K-Means k=3 (비지도) | LogReg 5-fold (지도) |
| 측정 대상 | HI 공간의 군집 구조 | 실제 Lo/Mid/Hi 레이블 분류 성능 |
| 목적 | "데이터 내 분리 가능한가" | "실제로 맞힐 수 있는가" |

acc가 m 선정에 더 직접적인 지표다.

### Q4. MIT와 HUST를 분리해서 보는 이유는?

두 데이터셋은 셀 화학 및 실험 조건이 달라 HI 분포가 다를 수 있다. 플롯에서 MIT/HUST를 같은 패널에 겹쳐 놓으면 데이터셋 편향이 군집처럼 보일 위험이 있다.

분리된 패널에서 같은 레벨 내 MIT와 HUST의 분포가 유사하다면 모델 일반화 가능성이 높다. 반대로 한쪽이 뭉쳐 있고 다른 쪽이 분산되어 있다면 데이터셋 특성이 군집 구조를 지배하는 것이다.

### Q5. Top-20 HIs by mRMR 막대 차트에서 MI 순서가 맞지 않는 이유는?

bar chart의 **순서는 mRMR 선택 순**이고, **막대 높이는 그 HI의 MI 값**이다. mRMR은 MI 순서가 아닌 `relevance - redundancy` 점수 순으로 선택한다.

```
예) discharging:
  Step 1: stat_v_range  MI=1.075  → 최고 MI, 첫 번째 선택 (MI 순서와 일치)
  Step 2: lfp_v_flatness MI=0.681  → MI 순위는 낮지만 stat_v_range와 상관 낮아 선택
  Step 3: lfp_v_concavity MI=1.011 → MI가 높지만 Step2까지 중복 없어서 3위 등장
```

따라서 막대가 단조 감소하지 않는 것은 정상이다. "MI가 높은 순"이 아닌 "이미 선택된 것들과 중복되지 않으면서 유효한 순"으로 선택된 결과다.
