### C-3. 비단조 관계 분석 (Mutual Information vs ρ)

Spearman ρ ≈ 0이더라도 비선형 관계가 존재할 수 있음 → MI 분석.

**이론 근거**: Gaussian 가정 하 `I(X;Y) = −½ ln(1 − ρ²)`  
→ MI >> 이론값이면 비단조(non-monotonic) 관계 존재

## D. 분류기 HI 선정 방향

### D-1. 선정 절차 (ε² 기반 4단계)

```
Step 1: |ρ| ≥ 0.7 AND 방향 일치율 ≥ 80% → 1차 후보 (강한 단조 HI)
Step 2: 1차 후보 내 피처 간 Spearman |ρ_feat| ≥ 0.9 → 고상관 쌍 중 대표 1개 선택 (중복 제거)
Step 3: 시나리오 구분 능력 ε² ≥ 0.1 (Kruskal-Wallis) → 시나리오(hi/mid/lo) 분리 가능 HI 우선
Step 4: MI 분석 — ρ 낮지만 MI 높은 HI 추가 검토 (비선형 모델용)
```
