#   1) conda create -n LFP_SOH_ESTIMATION python=3.10

#   3) torch/torchvision/torchaudio는 CUDA 11.6 빌드라 PyPI 기본 인덱스에 없음 —
#      먼저 별도로 설치:
#        pip install torch==1.12.1+cu116 torchvision==0.13.1+cu116 torchaudio==0.12.1+cu116 ^
#            --extra-index-url https://download.pytorch.org/whl/cu116
#      (대상 PC의 NVIDIA 드라이버가 CUDA 11.6과 호환되는지 먼저 확인할 것 —
#      GPU가 없거나 드라이버가 너무 오래되면 이 설치/torch.cuda.is_available()이
#      실패한다. 그 경우 +cu116 접미사를 빼고 CPU 빌드로 설치)
#   4) 나머지 전부:
#        pip install -r total_requirements.txt
